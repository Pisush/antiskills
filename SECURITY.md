# Security and personal data

**A security problem** in this repo, for example in the workflow that turns issues into rules: please report it privately through [GitHub's private vulnerability reporting](https://github.com/Pisush/antiskills/security/advisories/new). Do not open a public issue.

**Personal data in an issue**, yours or someone else's: use the same private report, or flag the issue. We delete the whole issue, not just the text, because GitHub keeps edit history.
