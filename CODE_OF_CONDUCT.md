# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, describe patterns rather than people, and never name or shame the senders of the examples.

Report problems privately through [GitHub's private vulnerability reporting](https://github.com/Pisush/antiskills/security/advisories/new).
